# 公众号写作风格规范 v1.0

> 基于125篇AI评分<40的竞品文章深度分析提取
> 目标：每篇文章AI评分控制在40分以下
> 生效日期：2026-04-11

---

## 一、核心原则：像真人一样思考和写作

### 1.1 人写文章的6大基因特征（从竞品分析中提炼）

**特征1：有具体的一手信息，而非泛泛而谈**
- ✅ 好："警方通报显示，徐某在微信群内发表侮辱性言论，被行政拘留7日"
- ❌ 坏："该事件引发了广泛关注，社会各界对此表达了强烈关注"
- **关键技巧：** 每个论点必须附带至少一个具体细节——数字、名称、时间、地点、原话引用

**特征2：语言节奏不均匀，有自然的波动感**
- ✅ 好：长短句交替，偶尔插入口语化表达
- ❌ 坏：每个段落长度相近，句式结构高度对称
- **关键技巧：** 故意打破规律——一段3行，下段8行；一句5个字，下一句40个字

**特征3：有明确的主观态度和情感表达**
- ✅ 好："说实话，看到这个消息我第一反应是：这操作太秀了"
- ❌ 坏："这一事件具有重要的意义和深远的影响"
- **关键技巧：** 每300字至少出现1次主观判断词（我觉得/说实话/不得不说/最让我意外的是）

**特征4：包含真实的时间线/事件进展，而非静态描述**
- ✅ 好："4月9日晚首发→凌晨3点破10万阅读→上午登上热榜"
- ❌ 坏："该事件在网络上迅速传播，引起了广泛讨论"
- **关键技巧：** 用时间轴叙事，带读者经历事件发展过程

**特征5：有"意外感"和反直觉的信息**
- ✅ 好："但有一个细节很多人忽略了——""出人意料的是——""真正让我意外的不是X而是Y"
- ❌ 坏：所有信息都是可预测的套话
- **关键技巧：** 每篇文章至少设置1个"反转"或"冷知识"

**特征6：结尾不套路化，拒绝"总结+展望+呼吁"三件套**
- ✅ 好：以一个具体的思考/疑问/个人故事收尾
- ❌ 块："综上所述...让我们共同期待..."
- **关键技巧：** 结尾要么留一个开放问题，要么分享一个相关的小故事，要么来一句大实话

### 1.2 AI高分文章的典型症状（必须避免）

| 症状 | 表现 | 解决方案 |
|------|------|---------|
| 句式工整 | 每段开头都是"首先/其次/最后" | 随机变换过渡词 |
| 段落均等 | 每段4-5行，高度一致 | 故意做长短段落交替 |
| 正确的废话 | 看似有道理但无实质内容 | 删掉所有可以套用到任何话题的句子 |
| 无作者存在感 | 全程没有"我" | 注入个人视角和体验 |
| 小标题对称 | "一、背景 二、分析 三、影响" | 用更有趣的小标题或不要小标题 |
| 配图概念化 | AI生成的抽象概念图 | 用实拍图/数据图表/截图 |

## 二、法律风险规避规则（强制执行）

### 2.1 内容红线（绝对不能碰）

**政治敏感类 — 零容忍：**
- 不涉及国家领导人姓名、评价、私生活
- 不评论政府政策优劣（可客观陈述事实，不加评判）
- 不涉及台湾/香港/西藏等敏感议题的立场表态
- 不转载未经证实的外交/军事信息
- 不使用可能引发误解的政治隐喻

**人身权益类 — 严格审查：**
- 不曝光普通人隐私（姓名需打码，照片需处理）
- 不对当事人进行道德审判（用"网友认为"替代"我认为他错了"）
- 引用他人言论时标注来源，不歪曲原意
- 不传播未经证实的谣言（必须标注"尚未核实"）
- 对涉案人员用"涉嫌/被指/据称"，不用确定性表述

**商业法律类 — 谨慎处理：**
- 不对上市公司股价做预测性陈述
- 不推荐具体理财产品
- 不贬低竞争对手品牌
- 使用"据公开数据显示"而非"事实是"
- 涉及专利/版权争议时保持中立

**社会风险类 — 主动规避：**
- 不煽动群体对立（地域/性别/职业/年龄歧视）
- 不渲染恐慌情绪（灾难/疫情/安全事故）
- 不使用标题党误导性表述（"震惊""必看""不看后悔"）
- 不编造虚假数据或案例

### 2.2 图片法律红线

**版权安全：**
- 不使用未授权的明星/名人照片
- 不使用带有明显logo的品牌图片（除非正面报道）
- 不使用网络搜索的随机图片（可能有版权陷阱）
- 所有配图优先使用AI原创生成

**肖像权：**
- 人物图片一律使用AI生成（非真人肖像）
- 如必须使用真实人物照片，需确保为公开场合新闻照
- 绝不使用偷拍/私人场合照片

**内容安全：**
- 不生成任何暴力、血腥、色情图片
- 不生成政治讽刺漫画
- 不生成宗教敏感图像
- 图片中不出现国旗/国徽/党徽等国家象征（除非正式新闻报道场景）

### 2.3 免责声明模板

每篇文章末尾自动附加：

```
---
*声明：本文基于公开信息整理，仅供参考。文中观点仅代表个人看法，不构成投资建议或其他专业建议。如有侵权请联系删除。部分图片由AI生成。*
```

## 三、写作实操清单（发布前自检）

### 3.1 AI评分自检（目标：< 40分）

发布前逐条检查：
- [ ] 文章是否有至少3处具体数字/名称/时间？
- [ ] 是否有"我"的主观视角出现？
- [ ] 段落长度是否参差不齐？
- [ ] 是否有至少1处口语化表达？
- [ ] 结尾是否避免了套路化总结？
- [ ] 是否有1个让人"没想到"的信息点？
- [ ] 小标题是否有趣/不规整？

### 3.2 法律安全自检

- [ ] 是否有任何可能被视为造谣的表述？→ 改为"网传/据报道/尚待核实"
- [ ] 是否涉及对具体个人的负面评价？→ 删除或改为客观陈述
- [ ] 是否使用了绝对化用语？"最好/唯一/第一" → 改为"之一/领先/优秀"
- [ ] 数据是否注明来源？"数据显示" → "据XX机构报告显示"
- [ ] 标题是否夸大？检查是否与正文匹配

## 四、低分文章写作公式（可直接套用）

### 公式A：热点追踪型（适合时事热点）
```
第1段：个人反应开场（"我刚刷到这个消息的时候..."）+ 具体时间点
第2段：事件核心事实（5W1H，带具体数字和名称）
第3段：【反转/意外】一个多数人没注意到的细节
第4段：多方反应对比（A说了啥/B说了啥/C网友咋说），带原话引用
第5段：我的真实想法（可以有偏见、可以有纠结、可以有不确定）
第6段：关联类比（这件事让我想到之前XX那件事...）
结尾：一个开放问题 或 一个相关小故事
```

### 公式B：科普讲解型（适合科技/知识类）
```
第1段：从一个具体的生活场景切入（"你有没有遇到过这种情况..."）
第2段：用一个离谱但好懂的比喻解释核心概念
第3段：拆解3个关键点（但不用"第一第二第三"，用更自然的方式）
第4段：【冷知识】这个领域的一个反直觉的事实
第5段：实际应用（这东西跟你的关系/怎么用它）
第6段：行业现状（哪些公司在做/做到了什么程度/还有啥难题）
结尾：我个人最期待的方向是XXX / 或者一个有趣的脑洞
```

### 公式C：深度观点型（适合争议话题）
```
第1段：抛出一个可能得罪人的观点（"接下来我要说的话可能有人不爱听"）
第2段：先承认对立面有道理（"我理解为什么很多人觉得..."）
第3段：但是——转折（"但如果我们换个角度看..."）
第4段：拿出具体证据支撑我的观点（案例/数据/亲身经历）
第5段：预判反驳（"肯定有人会说XXX，我的回应是..."）
第6段：退一步说（"当然，我也不是说我完全对..."）
结尾：邀请讨论（"你怎么看？评论区聊聊"）
```

## 五、已验证的低分账号风格参考

### 最值得模仿的账号及特点：

| 账号 | 特点 | AI分数区间 | 可学习什么 |
|------|------|-----------|----------|
| 差评 | 口语化极强，个人色彩浓 | 15-25 | 语言风格的松弛感和幽默感 |
| 虎嗅 | 观点鲜明，有作者风格 | 20-30 | 敢于表达明确立场 |
| 澎湃新闻/FactCheck | 一手调查，完整时间线 | 5-10 | 信息密度和溯源能力 |
| 新京报/我们视频 | 探访+故事化叙述 | 8-15 | 把硬新闻讲成有温度的故事 |
| 网易体育/NBA | 数据驱动+情绪表达 | 8-15 | 专业术语和粉丝情绪的结合 |

### 这些账号的共同DNA：
1. **永远从具体细节开始**，不从宏大叙事开始
2. **永远有时间感**，读者能感受到事件在流动
3. **永远有作者的存在**——不是上帝视角，是一个活人在跟你聊天
4. **永远给读者新信息**——不是把已知的东西重新排列组合
